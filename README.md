# Home Maintenance Checklist for Homeowners

A practical home maintenance checklist to help homeowners organize seasonal repairs, preventive maintenance, and small DIY improvement projects.

## Monthly Home Maintenance

- [ ] Inspect visible plumbing fixtures for leaks.
- [ ] Test smoke and carbon monoxide alarms according to manufacturer instructions.
- [ ] Check HVAC filters and replace them when necessary.
- [ ] Inspect bathroom and kitchen caulking for deterioration.
- [ ] Check doors and windows for drafts.

## Spring Maintenance

- [ ] Inspect gutters and downspouts for debris.
- [ ] Examine exterior paint and siding for damage.
- [ ] Check windows and doors for damaged weatherstripping.
- [ ] Inspect patios, walkways, and exterior surfaces.

## Summer Maintenance

- [ ] Check outdoor drainage around the home.
- [ ] Inspect decks and exterior woodwork.
- [ ] Identify areas needing touch-up painting.
- [ ] Review cooling system maintenance requirements.

## Fall Maintenance

- [ ] Clear gutters where safely accessible.
- [ ] Check exterior door seals.
- [ ] Prepare outdoor plumbing for freezing temperatures where applicable.
- [ ] Arrange professional heating system maintenance when required.

## Winter Maintenance

- [ ] Inspect accessible areas for moisture and condensation.
- [ ] Monitor exposed plumbing for freezing risks.
- [ ] Check weatherstripping around exterior doors.
- [ ] Review indoor ventilation and humidity levels.
